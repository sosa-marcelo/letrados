Class: ErrorDominio

ErrorDominio(codigo, estado, mensaje, detallesopt)

Error de dominio. Lo lanza la capa domain cuando una regla de negocio no se cumple. Lleva su propio codigo y estado HTTP para que api lo traduzca a respuesta sin que domain tenga que conocer Express.

domain NO deberia importar nada de HTTP; esta clase es la excepcion acordada: un numero de estado es un dato, no una dependencia de framework.

Constructor

new ErrorDominio(codigo, estado, mensaje, detallesopt)

Parameters:

identificador estable, en MAYUSCULAS (p. ej. EMAIL_DUPLICADO).

codigo de estado HTTP.
mensaje string

texto para el usuario final. Sin datos internos.

errores puntuales.
