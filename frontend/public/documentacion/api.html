Letrados API (2.0.0)

Download OpenAPI specification:

API de Letrados. Ciclo 1: autenticacion (modulo 1). Ciclo 2: usuarios y roles (modulo 2) y catalogo de libros (modulo 3).

Las sesiones son revocables: cada token lleva un jti registrado en el servidor, y cerrar sesion, bloquear una cuenta o darla de baja lo invalida al instante. El rol se lee de la base en cada peticion, no del token.

Todas las respuestas son JSON. Los errores tienen siempre la misma forma:

{ "error": { "codigo": "DATOS_INVALIDOS", "mensaje": "...", "detalles": [] } }

El usuario de la sesion expone solo id, nombre, email y rol; nunca el hash de la contrasena (RNF-08). El correo solo sale para su dueño y para el administrador; el perfil publico nunca lo muestra (RF-08).

Un recurso privado ajeno responde 404 NO_ENCONTRADO, no 403: un 403 confirmaria que el id existe.

Cualquier ruta bajo /api que no exista responde 404 RUTA_NO_ENCONTRADA con esa misma forma de error: el router de la API termina en un manejador propio, asi que nunca devuelve el HTML de la aplicacion.
